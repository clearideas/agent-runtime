Document Chat

Chat with an editor about a Word document. Attach a .docx, or use the sample proposal, and ask for changes. Every message is one run: the newest version is read inside the run sandbox, the model decides the edits, and a new .docx is written next to it. The files stay in a workspace the host keeps for this conversation, filed by turn; the conversation only names them.
