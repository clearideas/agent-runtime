# Sales data

Quarterly figures for the four sales regions, in US dollars.

| File                 | Contents                                           |
| -------------------- | -------------------------------------------------- |
| `regional_sales.csv` | Revenue per region and quarter, 2025-Q1 to 2026-Q2 |
| `deals.csv`          | Closed deals per account, region, and quarter      |

Quarters are written `YYYY-Qn`. The latest complete quarter is 2026-Q2.
